# [Agent] 配置缓存失效策略

## 背景

运行时为减少重复构建 Eino Agent，后续可能缓存由 `AgentDefinition` 构建出的 Agent。
如果 Agent 的 Prompt、模型配置、Skill 列表或启用状态被修改，旧缓存会继续生效，导致调用结果与当前配置不一致。

## 当前处理

第一阶段不缓存 Eino Agent。每次运行根据当前 AgentDefinition 构建运行时对象，因此本问题不阻塞当前 Agent 定义和运行链路开发。

## 后续要做

- 定义缓存键和缓存生命周期；
- Agent 更新、启用、停用后主动失效；
- 避免运行中的 Agent 受配置更新影响；
- 为缓存命中、失效和构建失败补充指标与测试。

## 验收标准

- 更新 Prompt、模型或 Skill 后，下一次新运行读取新配置；
- 停用 Agent 后，缓存不能继续让新请求执行；
- 已开始的运行保留启动时配置快照，不因缓存失效而改变行为；
- 并发更新和运行时不出现旧配置永久存活或空对象执行。
